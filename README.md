# structure_analysis
Activation Structure Analysis
Overview

This project analyzes user behavior data from a financial application to understand the structural drivers of enrollment conversion.

Instead of focusing only on overall conversion rates, this analysis explores:

Screen exploration patterns

Core feature exposure

Enrollment speed (Activation timing)

Dataset

Source: Kaggle – Financial Application Behavior Dataset

~50,000 users

User interaction logs

Enrollment indicator

Key Findings
1. Overall Enrollment Rate

~62%

2. Screen Exploration Matters

Users exploring 20+ screens showed a 74% enrollment rate.

3. Core Feature Exposure

Users who accessed Credit-related screens had a 68% enrollment rate compared to 56% for others.

4. Enrollment Speed

Most enrollments occurred within the first day.

Fast enrollers explored more core features.

Strategy Implications

Emphasize early exposure to core financial features

Optimize first-day onboarding

Reduce friction in feature discovery
